01 / Get ready

Installation.

Helvetia is a mod for Minecraft Java Edition. It requires NeoForge; it does not run in an unmodified vanilla profile, Bedrock, Fabric or Forge. Use Minecraft 1.21.1, NeoForge 21.1.265 and Java 21.

CURSEFORGE APP (available soon)

Import the ready-made profile

  1. Download the CurseForge profile ZIP from the release you are installing. Leave it zipped.
  2. Open the CurseForge app and select Minecraft.
  3. Choose Import (or Create Custom Profile → Import), then select the ZIP.
  4. Allow the app to install Minecraft 1.21.1 and NeoForge 21.1.265, then launch the profile.

This is a sharing profile containing Helvetia, not a published CurseForge project. If import fails, use the manual route below.

Already have a compatible CurseForge profile?

Open its folder, put the Helvetia JAR in mods, remove older Helvetia JARs, and restart. For a new manual profile, select Minecraft 1.21.1 and NeoForge 21.1.265.

MINECRAFT LAUNCHER

Install the JAR yourself

  1. Run Minecraft Java 1.21.1 once, then close it.
  2. Install NeoForge 21.1.265 from the official site. The installer needs Java 21.
  3. Select the NeoForge installation in the launcher. A separate game directory keeps this mod setup easy to manage.
  4. Put the downloaded JAR in that installation’s mods folder. Create the folder if needed. Do not unzip the JAR.
  5. Launch NeoForge and check the Mods list for Helvetia.

To update, close the game and replace the old Helvetia JAR. Keep only one version installed.

02 / Better together (still needs testing)

Multiplayer.

Install the same Helvetia version, Minecraft 1.21.1 and NeoForge on every player’s client and on the server. A vanilla server cannot load this mod. LAN play also requires compatible modded clients.

A shared evening

Race down a snowy course, ring cowbells at the finish, and gather for fondue or raclette. Meals share their servings; sleds have two seats; each musician needs their own horn.

Updating a group

Stop the server, back up the world, replace the old Helvetia JAR in the server’s mods folder, and have everyone update before reconnecting. Keep client and server versions matched.

03 / A few useful answers

Answers to possible questions.

Which keys are Sneak, Use and the alternate hand on PC and Mac?
Default Minecraft Java Edition controls
ActionPC (Windows / Linux)Mac
Sneak / crouchHold Left ShiftHold Left Shift (⇧)
Use item / place blockRight mouse buttonRight mouse button, or a two-finger secondary click on a configured trackpad
Swap main hand and offhandFF (the letter key)

The alternate hand is called the offhand. Press F to swap the selected hotbar item with the offhand item, or place an item in the offhand slot in your inventory. For fondue, keep the fork in your main hand and bread cubes in your offhand.

“Sneak-use” means hold Left Shift while using/right-clicking. “Hold Use” means keep the use button held down, for example while eating.

On Mac, enable Secondary click in System Settings → Trackpad (or Mouse). A mouse with a right button is convenient for holding Use. If you have changed your bindings, check Options → Controls → Key Binds for Sneak, Use Item/Place Block and Swap Item With Offhand.

The mod doesn’t appear.

Check that you launched NeoForge 21.1.265 with Minecraft Java 1.21.1, and that the JAR is in that installation’s mods folder.

I can’t eat the bread or raclette.

Try Survival with some hunger missing, and look away from blocks while holding Use. For fondue, load the fork with bread, then dip into a heated pot first. Release Use before loading another bite.

The fondue is cold.

Light its réchaud with flint and steel and wait five seconds after adding cheese. The shared pot must contain cheese portions.

The raclette won’t melt.

Place a lit campfire directly beside the stand at the same height. Rotate the cut face toward the fire using an empty hand, then wait.

Ingredients don’t run out.

Creative mode preserves added ingredient stacks. Test ingredient consumption and eating in Survival.

Where are the wild herbs?

Look in newly generated meadow terrain at Y=100+. Previously explored chunks won’t gain new patches. You can also craft seeds from wheat seeds and a dandelion. The herbs will not appear in land that was generated before the mod was installed.

How do I check a download?

Compare your file’s SHA-256 with SHA256SUMS.txt. On macOS use shasum -a 256 filename.jar; in Windows PowerShell use Get-FileHash filename.jar -Algorithm SHA256. A matching checksum detects changed bytes; it is not a security certification.

How do I report a problem?

Submit an issue on GitHub. Use the Issues tab in the GitHub repository hosting this page.

Include your Helvetia, Minecraft and NeoForge versions, steps to reproduce, single-player or server context, other installed mods, and a screenshot or relevant log excerpt. Remove personal information and credentials before sharing logs with the maintainer.
